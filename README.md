## Фиксация seed и воспроизводимость

Случайность в коде есть в трёх местах, и все три зафиксированы:

1. **Корпус и батчи** (`dz1-bughunt.ipynb`, ячейка обучения): `torch.manual_seed(0)` стоит
   перед построением корпуса — и текст, и разбиение на батчи одинаковы от прогона к прогону.
2. **Инициализация модели и dropout**: идут после того же `torch.manual_seed(0)`, поэтому
   начальные веса и маски dropout тоже воспроизводимы.
3. **Генерация**: перед генерацией стоит `torch.manual_seed(0)`, чтобы пример текста был
   одинаковым даже при повторном запуске только этой ячейки.

Единичное место, где PyTorch может дать расхождение между разными машинами, — это
недетерминированные операции на GPU; на CPU (и в Colab при `torch.manual_seed`) прогон
повторяется бит-в-бит. Если запускать только часть ячеек без перезапуска обучения,
значения потерь на графике будут другими (см. README — порядок ячеек сверху вниз).
